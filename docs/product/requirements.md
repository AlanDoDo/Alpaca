# 产品需求与 MVP 范围

## 产品定位

TechAlpaca 是围绕 AI、机器人、金融和个人思考的个人互联网空间。第一阶段先做好内容发布、发现和阅读；后续逐步加入社区和用户身份。

## 用户与核心任务

1. 访客浏览主题、发现文章、阅读和分享链接。
2. 作者通过 Git 管理 Markdown/MDX 文章并部署发布。
3. 后续注册用户创建社区帖子、回复并维护个人资料。

## 页面信息架构

| 路径 | 第一阶段行为 | 后续扩展 |
| --- | --- | --- |
| `/` | 主题 Hero、Featured、Latest、Topics | 社区动态入口 |
| `/blog` | 分类筛选、按日期浏览 | 标签、分页 |
| `/article/[slug]` | 静态文章、metadata、Markdown | 评论、收藏、相关文章 |
| `/forum` | 社区入口与阶段说明 | 帖子列表、分类、排序 |
| `/forum/[id]` | 阶段说明 | 帖子、回复、互动 |
| `/about` | 产品与作者介绍 | 身份与社区准则 |
| `/search` | 内容搜索入口 | 标题、正文、标签和分类查询 |
| `/login` | 身份接入前说明 | Supabase Email/OAuth |
| `/profile/[username]` | 身份接入前说明 | 公开资料、文章、帖子、关注 |
| `/settings` | 身份接入前说明 | 用户资料和隐私设置 |

## MVP 验收

- 文章来自仓库的 Markdown 文件，按 frontmatter 生成列表和静态详情页。
- 首页和内容页在窄屏可阅读，页面使用语义化标题和链接。
- 每篇文章有标题、摘要、发布日期和分类，并能生成独立 metadata。
- 应用能够在配置了环境变量后本地开发并生成生产构建。
- 未接入后端的社区/账号能力明确标记为规划中，不接受或丢弃用户输入。

## 视觉与内容约束

使用深灰、白和纸白，电蓝只做少量交互强调。布局偏编辑部与技术媒体，列表以排版和留白为主。避免仪表盘卡片堆叠、霓虹效果和 Web3 营销视觉。

## 非目标

首期不实现区块链、代币、NFT、DID 登录、微服务、独立后端服务器或 AI 问答。身份和社交协议仅记录扩展点。
