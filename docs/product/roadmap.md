# 产品路线图

## Phase 1：个人内容

Git 中的 MDX、编辑式首页、博客分类与详情、SEO、RSS、站点地图和部署流程。

## Phase 2：社区

Supabase Auth、profile、帖子、回复、点赞、收藏、关注、举报与通知。发布前建立社区规范、moderation 权限和 RLS。

## Phase 3：个人身份

稳定的内部主体 ID、外部身份绑定、可验证的账户设置、授权撤销和身份迁移流程。

## Phase 4：社交图谱

关注关系、动态 feed、社区归属和信誉信号；明确隐私、排序与反滥用设计。

## Phase 5：开放社交协议

评估 DID、Verifiable Credentials、钱包身份、AT Protocol、Farcaster、IPFS/Arweave 与 P2P 存储。按照互操作性、用户迁移能力和运营成本做小范围验证。

## AI 扩展

AI 搜索、摘要、相关文章和内容问答作为独立能力评估。需注明引用来源、数据范围、用户授权及生成内容风险；不作为 Phase 1 上线依赖。

阶段向前推进由使用需求和维护能力驱动。路线中的项目是探索方向，不代表承诺或当前实现状态。
