# 博客体验优化记录

更新：2026-09-26。沿用白昼 / 暗夜主题，优先阅读与写作。

## 1. 手机端

- 导航点击区域至少 44px，手机端工作台输入与搜索框使用 16px 字号，避免输入时页面自动放大。
- 长表格独立横向滚动，代码保持格式，长链接可以换行。
- 发布确认弹窗限定视口高度，内容较长时内部滚动。

## 2. 阅读

- Markdown 代码块提供复制按钮和失败提示。
- 无链接的正文图片支持点击、Enter 或空格放大；原生 dialog 支持 Escape 关闭，关闭后恢复焦点。
- 图片预览复用已加载的图片 URL；保留原有长文章目录与相关文章。

## 3. 写作发布

- 新建前保存当前草稿，存储失败时停止切换。
- 发布前检查标题、摘要、路径、正文；清空正文需确认。
- GitHub 发布成功后保留浏览器草稿与最新 SHA，方便部署期间继续编辑。
- 手机端也提供导出按钮；导出包含正文和 frontmatter（标题、分类、标签、日期、封面等）。
- 封面仍使用图片地址，尚未接入本地文件上传。草稿保存在当前浏览器，跨设备需导出备份。

## 4. 机器人研究

- 机器人分类及标题 / 标签含机器人、具身智能的产业文章进入研究页。
- 行业观察、技术学习、项目实践按标题与标签分类；先匹配实践关键词，再匹配行业关键词，其余为技术学习。
- 首页展示一篇精选与最多七篇研究记录；后续页最多七篇，分类和页码保存在 URL。
- 没有项目文章时显示空状态，不编造作品。分类规则维护于 `src/app/forum/page.tsx`。

## 5. 性能

沿用文件解析缓存、搜索结果缓存、延迟加载音乐和编辑预览延迟更新。研究页封面加载尺寸设置桌面上限；搜索结果不批量预取文章。
实际线上首屏速度需要部署后使用浏览器性能工具测量，本次不声称获得新的性能分数。

## 6. 搜索

标题与摘要高亮关键词，弹窗 Tab 焦点限制在内部，关闭后恢复原焦点。
接口最多返回十篇，结果提示明确说明上限。

## 7. 上线维护

- About 与 Research 使用各自 canonical，站点提供默认分享图片。
- 部署步骤见 `docs/operations/deployment.md`，性能记录见 `performance.md`。
- 发布前将草稿导出；已发布文章通过 GitHub 历史恢复。`.env.local` 单独保存到密码管理器，不放入 Git。
- 新机器恢复依照 `migration.md`，文章及站内图片需一起迁移。
- 上线后按手机 / 桌面、白昼 / 暗夜检查首页、研究页、长文、搜索、后台，留意托管平台日志。
