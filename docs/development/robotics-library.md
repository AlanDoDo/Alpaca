# Research 分类与文章统一管理

## 当前方案（2026-09-27）

取消独立知识库，以普通博客文章统一管理。Research 专注机器人，AI 与金融仍使用独立页面。Research 只有简短介绍、全部与八个分类筛选、每页六篇文章；手机筛选横向滚动。

八类：产业与应用 industry、机械与执行机构 mechanics、电子与嵌入式 electronics、感知与定位 perception、规划与导航 navigation、运动与控制 control、机器人学习 learning、系统与工程 systems。定义在 src/modules/content/research.ts。

每篇文章保留一个主分类 category（机器人、AI、编程等），机器人子方向用 researchTopic 保存，具体技术用 tags。后台所有文章均可选择 Research 方向；明确指定方向的文章会进入 Research，未指定的机器人文章自动归类，发布与导出 Markdown 均保存此字段。旧文章缺少字段时有标题/标签兜底，已明确归类的机器人文章优先使用保存的分类。

## 内容与路径

前一轮导入的八篇笔记已迁移至 content/blog/*.mdx，统一进入搜索、文章库、Blog 与普通阅读页。C 语言归编程；YOLO、CNN、Transformer、强化学习、嵌入式基础保留原主分类，同时作为机器人相关技术文章纳入 Research。通用编程、网站、金融和随笔不自动收录。原始 F:/Note 文件未改动，图片继续使用 public/images/robotics。

旧 /forum/library 入口永久重定向到 Research，旧分类入口转到对应筛选，旧 /forum/notes/<slug> 转到 /article/<slug>，站点地图仅包含正式文章地址。

## 可选文章链接

双向链接继续支持 [[blog:stm32|STM32 学习笔记]] 和 [[文章标题]]。迁移文章保留旧 knowledge:<slug> 别名，避免已有引用失效。正文可以链接，阅读页引用/被引用列表默认折叠，不增加图谱入口。

固定 ID 和路径在编辑已有文章时锁定，改标题保留历史别名。草稿保存在浏览器，发布采用 GitHub SHA 冲突检查；发布到 GitHub 后，等待 Vercel 部署完成才更新线上页面。
