# 水墨视觉系统

更新：2026-09-27

## 设计原则

- 背景固定为纯白 `#ffffff` 和纯黑 `#000000`，界面强调色随主题使用深灰/浅灰。灰阶用于边框、次要文字与层次，不引入米白。
- 完整水墨太极只用于首页；Research、Notes、About、AI 与金融使用局部墨迹。文章正文与工作台编辑区不叠加装饰。
- 原有内容图片保留颜色；错误、保存状态保留语义颜色。
- 首页采用用户确认的同一张素材，保留原导航、文案、字体和首屏比例。

## 代码与资产

- `src/app/globals.css`：全站主题色令牌。
- `src/app/ink.css`：水墨布局、响应式和动效，紧随 globals.css 导入。
- `src/components/visual/ink-art.tsx`：服务端装饰组件，三个变体 hero / wash / fragment；空 alt、aria-hidden、pointer-events:none。
- `src/components/visual/ink-motion.tsx`：单个客户端控制器，IntersectionObserver 管理入场与画外暂停；路由更换时清理观察器。
- `public/images/ink/taichi-1280.webp`：确认的太极原稿压缩版，389576 字节。
- `public/images/ink/brush-640.webp`：栏目用抽象墨迹，80414 字节。
- 使用 next/image 的响应式尺寸；仅首页主视觉预加载，栏目装饰懒加载。

## 页面层级

| 页面 | 水墨处理 | 交互 |
| --- | --- | --- |
| 首页 | 右侧完整太极；手机改为文案下方 | 24 秒微幅呼吸、精选/最近更新入场 |
| Research | 页眉右侧淡墨 | 分类反馈、列表底线渐显 |
| Notes | 页眉局部笔触 | 保留瀑布流与已有卡片展开过渡 |
| About | 标题留白处淡墨 | 探索入口微移、书单区块入场 |
| AI | 页眉淡墨，精选配图改为笔触 | 主题区块入场 |
| 金融 | 原有图表后方淡墨 | 投机/投资区块入场，保留曲线动画 |
| 阅读页 | 标题前短墨线 | 正文保持静态可读 |

## 手机与无障碍

- 767px 以下首页采用单列，太极最大 320px，关闭装饰持续动画。
- 桌面、中屏分别调整太极位置和标题宽度，防止图文互相遮挡。
- 保留 Notes 单列、研究分类横向滚动、手机编辑工作台的原有适配。
- 系统减少动态效果时关闭新动画与平滑滚动。
- JS 未加载时内容默认可见；仅为屏幕下方区块启用渐入，键盘聚焦会显示内容。
- 装饰离开视口或浏览器标签进入后台时暂停动画。
- head 内的固定主题初始化脚本在首屏绘制前恢复偏好；禁用 localStorage 时切换仍可在当前访问使用。
