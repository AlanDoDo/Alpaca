# 网易云音乐胶囊

2026-09-27：按用户选择恢复网易云嵌入播放器，仅需歌单 ID，无需解析服务或 NETEASE_API_URL。删除本次新增的 /api/music 接口及解析配置。

入口是唱片造型胶囊，支持白昼/暗夜和手机布局。展开卡片只保留简短标识、原生网易云播放器、更换歌单和关闭按钮。播放器内置播放与切歌操作保持由网易云提供，网站不能读取当前歌曲、控制跨域播放器或修改其内部主题，因此入口不显示伪造的歌曲/播放状态。

桌面悬停展开，离开后延迟 350 毫秒收起，便于从入口移动到卡片；点击可展开/收起；手机点击使用。修改歌单期间不因鼠标移开而自动收起。快捷栏在播放器打开时保持展开。

歌单 ID 存储在浏览器 localStorage。页面加载完成后延迟 1.5 秒挂载播放器并尝试自动播放；浏览器可能要求用户手动点击播放。收起卡片保留 iframe，站内导航不主动中断音乐。

发布检查：类型检查、Lint、生产构建（117 页面）、现有安全回归和生产依赖审计均通过。浏览器检查桌面/390px 手机视口与白昼/暗夜主题；手机无横向溢出，胶囊文字不换行。主要页面及搜索返回 200，未登录后台读取 401，不存在页面 404。新增腾讯云图片通过 Next.js 图片接口返回 200。网易云 iframe 已加载，但没有验证实际声音输出或保证浏览器自动播放。

UI 再调整：移除播放器顶部标题栏与入口副标题，入口固定宽度并禁止文字换行。播放器外框采用统一浅色背景，底部细小标识与设置/关闭操作，避免暗色外框与内置白色播放器重复叠层。网易云 iframe 的内部配色仍由网易云提供。
