# 性能优化记录

2026-09-26：

- 博客和金融文件按修改时间、创建时间及大小缓存解析结果。每次访问检查文件元数据，内容编辑、增加及删除立即更新缓存；搜索小写索引随快照更新。
- 音乐 iframe 在首次打开播放器时加载，之后保持挂载，保留跨页连续播放。
- 管理员入口禁止自动预取，避免访客提前加载工作台。
- 首页全屏介绍下方的精选封面延迟加载，避免争抢首屏资源。
- 搜索在浏览器内缓存最多 20 个关键词，30 秒过期；继续保留防抖与请求取消。
- 写作台使用延后更新的 Markdown 预览，优先响应输入。
- 金融 PNG 通过 Next Image 根据实际宽高输出响应式图片；保留原图，延迟加载，并缓存优化图片至少一天。站内 `/images/` 资源缓存一天，过期可后台重新验证。
