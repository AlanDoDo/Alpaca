## 排查无法访问

需要错误码、访问者地区/运营商和准确网址。如果是 DNS、TLS 或连接超时，在请求到达应用前就可能失败，React/CSS 优化无法解决。

Vercel 官方说明大陆网络可能无法稳定访问其站点，推荐自定义域名：[访问说明](https://vercel.com/kb/guide/accessing-vercel-hosted-sites-from-mainland-china)。绑定自有域名可以改善部分可达性问题，但不能保证所有网络稳定；以控制台实际给出的 DNS 记录配置，勿盲目套用旧 IP。

如果主要访客在大陆，且自定义域名仍不稳定，可考虑面向这些访客的托管方案。是否迁移、选择区域或服务商，需要先明确访客地区与可用域名。

保留 Preview 部署保护、管理员认证、安全响应头。不要为解决连接超时关闭安全机制。
