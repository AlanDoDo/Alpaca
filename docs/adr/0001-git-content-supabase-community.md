# ADR 0001：文章进入 Git，用户生成数据进入 Supabase

- 状态：已采纳
- 日期：2026-09-25

## 背景

第一阶段以个人写作和 SEO 为中心，文章需要易于版本管理、静态生成和迁移；社区互动需要认证、关系约束和并发写入。

## 决定

文章以 MDX 文件保存在 Git。用户、profile、帖子、评论和关系数据未来放在 Supabase PostgreSQL；认证通过 Supabase Auth 接入。业务页面通过模块 API 与具体存储适配器交互。

## 后果

内容可以随仓库构建并保留完整历史。文章不能直接通过站内表单发布，直到建立经过审阅的内容管理流程。社区能力需要迁移文件、RLS 策略和隔离的 Supabase 环境。
